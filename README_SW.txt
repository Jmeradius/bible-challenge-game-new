BIBLE CHALLENGE GAME - ANDROID CLOUD BUILD STARTER

Hii ni Android project ya kuanza kujenga APK kupitia GitHub Actions bila kusakinisha Android Studio kwenye simu.

MUHIMU:
- APK inayotengenezwa hapa ni DEBUG APK ya majaribio, si release iliyosainiwa kwa Google Play.
- AdMob bado haijaunganishwa. Internet permission pekee haimaanishi matangazo yanafanya kazi.
- Kabla ya kuchapisha, hakiki masuala ya ruhusa za Biblia, privacy policy, app signing, na Google Play requirements.
- App inaweka HTML ya sasa ndani ya assets ili msingi wa mchezo ufunguke bila intaneti. Vipengele vinavyohitaji link ya umma bado vitahitaji hosting.

JINSI YA KUJENGA KWA SIMU:
1. Fungua github.com kwenye browser na ingia au tengeneza akaunti.
2. Tengeneza repository mpya (mf. bible-challenge-game) na iwe Private au Public kulingana na chaguo lako.
3. Pakia faili zote za ZIP hii kwenye repository, ukihakikisha .github/workflows/build-apk.yml ipo kwenye njia hiyo.
4. Fungua Actions > Build Bible Challenge APK > Run workflow.
5. Ikikamilika, fungua run iliyofanikiwa, shuka chini hadi Artifacts, pakua BibleChallengeGame-debug-apk.zip, ifungue na usakinishe app-debug.apk.

Kama upload ya faili nyingi kupitia simu ni ngumu, tunaweza kuchagua hatua mbadala ya kuzipakia kupitia GitHub web interface.
